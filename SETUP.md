# Como aplicar o visual no GitHub

## 1. Criar/editar o repositório de perfil

1. Entre em https://github.com/yanreissureicao
2. Abra o repositório chamado exatamente `yanreissureicao`. Se ele ainda não existir, crie um repositório público com esse nome.
3. Envie `README.md` e a pasta `assets/` para a raiz do repositório. A estrutura deve ficar assim:

```text
yanreissureicao/
├── README.md
└── assets/
    └── banner.png
```

4. Faça commit das alterações e volte à página do perfil.

## 2. Ajustes importantes

- O README usa inglês para ter um tom de portfólio internacional; você pode traduzir se preferir.
- A seção de projetos é genérica de propósito. Antes de publicar, substitua os links pelos repositórios reais e ajuste as tecnologias para refletir o que cada projeto realmente usa.
- Os cards de estatísticas são gerados por serviços externos e podem demorar a carregar ou ficar indisponíveis temporariamente.
- O README não consegue reproduzir a interface inteira do mockup: a barra lateral, o gráfico de contribuições nativo e a grade de repositórios fixados são controlados pelo próprio GitHub.

## 3. Para ficar mais parecido com a referência

1. No perfil, use **Customize your pins** e fixe até seis repositórios que você queira destacar.
2. Em cada repositório importante, adicione uma descrição curta, tópicos relevantes e um README com objetivo, tecnologias, funcionalidades e como executar.
3. Use o tema escuro do GitHub para combinar com o banner.
